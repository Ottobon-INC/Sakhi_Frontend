# Layer 4 — Clinic Portal & Staff Onboarding

This folder is the isolated workspace exclusively owned by the **Clinic Portal** teammate.

## Folder Structure
- `components/`: Clinic-specific components (e.g. triage review queue, staff cards, appointment lists).
- `api/`: Clinic API connectors and backend triage endpoints.
- `ClinicPage.jsx`: Main entry point for the Clinic Portal view.

Teammates working on Layer 4 can build out all clinical workflows inside this folder without touching `patient/` or risking merge conflicts.
