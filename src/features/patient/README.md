# Layer 1 — Patient Touchpoint (JanmaSethu PWA)

This folder contains all code, components, API clients, and translations exclusively owned by the **Patient Touchpoint PWA**.

## Folder Structure
- `components/`: UI components for the patient chat (ChatHeader, EscalationCard, ChecklistCard).
- `api/`: API client (`sakhiClient.js`) and mock handlers (`mockResponses.js`).
- `i18n/`: Multilingual localization for Telugu, Hindi, and English (`translations.js`).
- `PatientPage.jsx`: Main entry point for the Patient Touchpoint view.

Teammates working on Layer 1 can safely add features here without touching `clinic/`.
